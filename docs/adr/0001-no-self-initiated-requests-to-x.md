# xnote 不主动向 X 发请求

xnote 不用用户的登录凭据调用 X 的内部接口，页面上的全部请求都由 X 自己的代码发出。原因是主动调用有账号风控风险，并且接口参数一变脚本就失效。

## Consequences

- X 页面没有加载的数据，xnote 拿不到。
- 点赞、回复、转发、收藏只能靠 X 的原生界面完成，xnote 不自己实现这些交互。
- 触发 X 自己的翻页回调不算主动请求，但必须限制频率。
- 把 X 读到的时间线回答换成本地副本不算主动请求，见 ADR-0003。
- 「分享为图片」会从 X 的 CDN（pbs.twimg.com、video.twimg.com、abs.twimg.com）重新读取这一条帖子的图片、视频和字体。只在打开分享窗口和导出时发生，不带登录凭据，不调接口，不算主动请求。
