# 瀑布流重排 X 的原生帖子节点，并依赖 X 的内部实现

瀑布流不自己绘制卡片，而是用 CSS Grid 重排 X 的原生帖子节点，这样点赞等原生交互全部保留，也符合 ADR-0001。X 的时间线是虚拟列表，单靠 CSS 会让帖子消失和滚动跳动，所以 xnote 改写 X 内部 React 组件的私有方法，让已加载的帖子保持渲染，并调用 X 自己的翻页回调。做法参考了 MIT 许可的用户脚本「X.com Masonry View」，代码是 xnote 自己写的。

## Considered Options

- 读取时间线请求的响应，自己绘制卡片：不依赖 X 的页面结构，但是卡片上的点赞必须主动调用接口，违反 ADR-0001。

## Consequences

- X 改版后私有方法名会变。xnote 找不到这些方法时，必须自动退回 X 原生的单列时间线，并在设置面板里提示。
- 帖子不卸载，长时间滚动后内存持续增长。
